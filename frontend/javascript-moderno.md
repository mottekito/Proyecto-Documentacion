**JavaScript moderno**



1. Qué es JavaScript

JavaScript es un lenguaje de programación que permite añadir interactividad a las páginas web. Gracias a él, una página puede reaccionar a las acciones del usuario y modificar su contenido.

Se utiliza principalmente en frontend, aunque también puede funcionar en el servidor mediante Node.js.



2. Variables y funciones

Las variables permiten guardar información que puede utilizar un programa.

En JavaScript existen diferentes formas de declarar variables:

- `let`: permite crear variables cuyo valor puede cambiar.
- `const`: se utiliza para valores que no se van a reasignar.
- `var`: es una forma antigua de declarar variables.

Las funciones permiten agrupar instrucciones para realizar determinadas tareas y reutilizar el mismo código.



3. Elementos importantes

JavaScript dispone de diferentes herramientas que permiten crear aplicaciones más completas.

- DOM: permite acceder y modificar los elementos de una página.
- Eventos: permiten detectar acciones del usuario, como pulsar un botón.
- Arrays: sirven para guardar varios datos en una misma estructura.
- Objetos: permiten agrupar información relacionada.
- Módulos: ayudan a organizar el código en diferentes archivos.



4. JavaScript asíncrono

La programación asíncrona permite realizar tareas sin tener que esperar a que todas terminen para continuar ejecutando el programa.

Algunas de sus herramientas son:

- Promesas: representan el resultado de una operación que puede terminar más adelante.
- `async`: permite declarar funciones asíncronas.
- `await`: permite esperar el resultado de una promesa dentro de una función asíncrona.
