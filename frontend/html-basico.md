**HTML básico**



1. Qué es HTML

HTML es un lenguaje de marcado que se utiliza para crear la estructura de las páginas web. Permite organizar textos, imágenes, enlaces, tablas y otros elementos.

Es una de las tecnologías principales del desarrollo frontend y normalmente se utiliza junto con CSS y JavaScript.



2. Elementos principales

HTML utiliza etiquetas para indicar qué tipo de contenido se está mostrando.

Algunas de las más utilizadas son:

- `<html>`: contiene todo el documento.
- `<head>`: incluye información de la página.
- `<body>`: contiene el contenido visible.
- `<h1>`: sirve para crear títulos.
- `<p>`: permite escribir párrafos.
- `<a>`: crea enlaces.
- `<img>`: permite insertar imágenes.



3. Atributos HTML

Los atributos sirven para añadir información a las etiquetas o modificar su funcionamiento.

Algunos ejemplos son:

- `href`: indica la dirección de un enlace.
- `src`: indica la ubicación de una imagen.
- `alt`: proporciona una descripción de una imagen.
- `id`: identifica un elemento.
- `class`: permite agrupar elementos para aplicar estilos.



4. Organización de una página

Una página HTML suele estar dividida en diferentes partes para mantener el contenido ordenado.

- Cabecera: contiene información inicial de la página.
- Navegación: permite moverse entre diferentes apartados.
- Contenido principal: contiene la información más importante.
- Pie de página: incluye información adicional, como datos de contacto.
