**Frameworks de desarrollo web**



1. Qué son los frameworks

Los frameworks son herramientas que proporcionan una estructura y funciones preparadas para facilitar el desarrollo de aplicaciones.

Permiten ahorrar tiempo, organizar mejor el código y evitar tener que programar algunas funciones desde cero.

También existen bibliotecas, que ofrecen herramientas concretas para utilizar dentro de un proyecto.



2. Frameworks y herramientas frontend

Existen diferentes opciones para desarrollar la parte visual de una página web.

*React*

Es una biblioteca de JavaScript que permite crear interfaces de usuario mediante componentes reutilizables.

*Angular*

Es un framework que permite desarrollar aplicaciones web completas y organizar el proyecto de forma estructurada.

*Vue.js*

Es un framework progresivo de JavaScript que facilita la creación de interfaces y aplicaciones web.

*Bootstrap*

Es un framework CSS que incluye estilos y componentes preparados para crear páginas adaptables.



3. Ventajas de utilizar frameworks

Trabajar con frameworks tiene varias ventajas:

- Permiten ahorrar tiempo durante el desarrollo.
- Ayudan a mantener el código organizado.
- Facilitan la reutilización de componentes.
- Incluyen herramientas que ya están preparadas.
- Pueden facilitar el trabajo en equipo.



4. Elección de un framework

No todos los proyectos necesitan utilizar las mismas herramientas.

Para elegir una opción hay que tener en cuenta el tamaño del proyecto, los conocimientos del equipo, las necesidades de la aplicación y el tiempo disponible.

También es importante conocer la documentación y las actualizaciones de cada tecnología.
