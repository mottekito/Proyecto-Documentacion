**CSS avanzado**



1. Qué es CSS

CSS es un lenguaje que permite modificar el aspecto visual de las páginas web. Se utiliza para cambiar colores, tamaños, posiciones, fondos y otros elementos del diseño.

Trabaja junto con HTML para conseguir que las páginas tengan una apariencia más organizada y atractiva.



2. Selectores CSS

Los selectores permiten elegir los elementos HTML a los que queremos aplicar estilos.

Los más habituales son:

- Selector de etiqueta: selecciona elementos por su nombre.
- Selector de clase: utiliza un punto seguido del nombre de la clase.
- Selector de ID: utiliza el símbolo # para identificar un elemento concreto.



3. Modelo de caja

El modelo de caja explica cómo se organiza el espacio que ocupa cada elemento de una página.

Está formado por cuatro partes:

- Contenido: el texto o elemento que se muestra.
- Padding: espacio entre el contenido y el borde.
- Border: borde que rodea al elemento.
- Margin: espacio exterior que separa un elemento de otros.



4. Diseño de páginas

CSS incluye diferentes herramientas para organizar los elementos de una página.

*Flexbox*

Permite colocar elementos en filas o columnas y distribuir el espacio entre ellos.

*CSS Grid*

Permite organizar los elementos mediante filas y columnas, siendo útil para diseños más complejos.

*Diseño responsive*

Permite adaptar una página a diferentes tamaños de pantalla, como móviles, tablets y ordenadores.
