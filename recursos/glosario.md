**Glosario de desarrollo web**



1. HTML

Lenguaje de marcado utilizado para crear la estructura de las páginas web.



2. CSS

Lenguaje utilizado para dar estilo y diseño a los elementos de una página web.



3. JavaScript

Lenguaje de programación que permite añadir interactividad a las páginas web.



4. Frontend

Parte de una aplicación web que ve y utiliza directamente el usuario.



5. Backend

Parte interna de una aplicación que se encarga de procesar información y gestionar los datos.



6. Servidor web

Sistema que recibe peticiones de los usuarios y entrega el contenido de una página web.
