**Bases de datos**



1. Qué es una base de datos

Una base de datos es un sistema que permite almacenar y organizar información para poder consultarla, modificarla y gestionarla fácilmente.

Se utiliza en muchas aplicaciones, como tiendas online, redes sociales, bancos y plataformas educativas.



2. Tipos de bases de datos

Existen diferentes tipos de bases de datos dependiendo de cómo se almacena la información.

*Bases de datos relacionales*

Organizan los datos en tablas formadas por filas y columnas. Utilizan SQL para realizar consultas y gestionar la información.

*Bases de datos no relacionales*

Almacenan la información de formas más flexibles, por ejemplo mediante documentos o pares de clave y valor.



3. Sistemas de gestión de bases de datos

Los sistemas de gestión permiten crear, modificar y consultar bases de datos.

Algunos de los más utilizados son:

- MySQL: sistema relacional muy utilizado en aplicaciones web.
- PostgreSQL: sistema relacional conocido por sus funciones avanzadas.
- MongoDB: base de datos no relacional que utiliza documentos.
- SQLite: base de datos ligera que no necesita un servidor independiente.



4. Lenguaje SQL

SQL es un lenguaje utilizado para trabajar con bases de datos relacionales.

Algunas de sus instrucciones principales son:

- SELECT: permite consultar información.
- INSERT: añade nuevos registros.
- UPDATE: modifica datos existentes.



También son importantes para controlar los usuarios, productos, pedidos y otros datos de una página web.

5. Importancia de las bases de datos

Las bases de datos permiten mantener la información organizada, evitar pérdidas de datos y facilitar el acceso a la información desde diferentes aplicaciones.
