**Seguridad en el desarrollo web**



1. Qué es la seguridad web

La seguridad web consiste en proteger las páginas y aplicaciones frente a ataques, accesos no autorizados y posibles robos de información.

Es importante porque muchas aplicaciones manejan datos personales, contraseñas y otra información privada.



2. Amenazas más comunes

Existen diferentes ataques que pueden afectar a una página web.

- SQL Injection: intenta introducir instrucciones SQL maliciosas en una aplicación.
- Cross-Site Scripting (XSS): permite introducir código malicioso que puede ejecutarse en el navegador de otros usuarios.
- Phishing: intenta engañar a los usuarios para conseguir sus datos.
- Ataques de fuerza bruta: prueban muchas contraseñas hasta encontrar la correcta.
- Denegación de servicio (DoS): intenta dejar un servicio sin funcionar mediante un gran número de peticiones.



3. Medidas de protección

Para mejorar la seguridad de una aplicación se pueden utilizar diferentes medidas:

- Utilizar contraseñas seguras.
- Mantener los programas y servidores actualizados.
- Validar los datos que introduce el usuario.
- Limitar los permisos de cada usuario.
- Realizar copias de seguridad.
- Proteger las comunicaciones mediante HTTPS.



4. Autenticación y autorización

Son dos conceptos importantes dentro de la seguridad.

*Autenticación*

Permite comprobar quién es un usuario, por ejemplo mediante un nombre de usuario y una contraseña.

*Autorización*

Determina a qué partes de una aplicación puede acceder un usuario y qué acciones tiene permitidas.



5. Importancia de la seguridad

Una buena seguridad ayuda a proteger la información de los usuarios, evitar problemas en los servidores y mantener la confianza en una aplicación.

Por eso, la seguridad debe tenerse en cuenta desde el principio del desarrollo y no solamente cuando la aplicación ya está terminada.
