**APIs REST**



1. Qué es una API

Una API es un conjunto de reglas que permite que diferentes programas o aplicaciones puedan comunicarse entre sí.

Por ejemplo, una página web puede utilizar una API para obtener información de un servidor o consultar los datos de un usuario.



2. Qué es REST

REST es un estilo de arquitectura que se utiliza para diseñar servicios web.

Las APIs REST permiten intercambiar información entre aplicaciones mediante peticiones HTTP y suelen utilizar formatos como JSON para enviar los datos.



3. Métodos HTTP principales

Las APIs REST utilizan diferentes métodos para trabajar con los recursos.

- GET: obtiene información.
- POST: crea un nuevo recurso.
- PUT: actualiza un recurso completo.
- PATCH: modifica una parte de un recurso.
- DELETE: elimina un recurso.



4. Cómo funciona una API REST

Su funcionamiento suele seguir estos pasos:

- Una aplicación realiza una petición al servidor.
- La API recibe la petición.
- El servidor procesa la operación solicitada.
- La API devuelve una respuesta.
- La aplicación utiliza los datos recibidos.

Las respuestas suelen incluir un código de estado HTTP para indicar si la operación se ha realizado correctamente.



5. Ventajas de las APIs REST

- Permiten comunicar diferentes aplicaciones.
- Utilizan protocolos y formatos habituales.
- Facilitan la separación entre frontend y backend.
- Pueden utilizarse desde ordenadores y dispositivos móviles.
- Permiten reutilizar servicios en diferentes proyectos.
